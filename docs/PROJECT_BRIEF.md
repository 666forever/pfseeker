# Project brief

## Product

**pfseeker** is a curated media discovery platform for profile pictures, banners, icons, and user-created aesthetic collections.

## Brand

- Main expressive mark: `.pfseeker®`
- Normal product name: `pfseeker`
- Expansion: profile seeker
- Domain: `https://pfseeker.com/`

The dot and registered-symbol treatment should be used deliberately rather than repeated in all prose and metadata.

Recommended usage:

| Context                           | Form         |
| --------------------------------- | ------------ |
| Hero or primary brand composition | `.pfseeker®` |
| Navigation wordmark               | `pfseeker`   |
| Metadata and schema               | `pfseeker`   |
| Footer and legal copy             | `pfseeker`   |
| Social campaign graphics          | `.pfseeker®` |

## Primary user goals

1. Discover suitable profile media quickly.
2. Search and narrow results without losing context.
3. Preview assets at useful sizes.
4. Save several assets into a temporary or synced collection.
5. Download one asset or a complete collection reliably.
6. Follow creators and explore related visual styles.
7. Submit media through a controlled moderation process.

## Core public surfaces

- Homepage
- PFP gallery
- Banner gallery
- Icon gallery
- Search results
- Category pages
- Tag pages
- Individual asset pages
- Collections directory
- Individual collection pages
- Creator profiles
- Creator leaderboards
- About, FAQ, privacy, and terms pages

## Account surfaces

- Discord sign-in
- Account overview
- Saved and created collections
- Submission history
- Settings

## Administrative surfaces

- Pending submissions
- Asset management
- Category and tag management
- Reports
- User and role management
- Moderation history

## Product principles

- Image-first without sacrificing usability.
- Fast browsing even with a very large library.
- Search and filters represented in shareable URLs.
- No dead controls or decorative functionality.
- Public content remains crawlable without JavaScript.
- Original brand identity rather than a clone of the assessed reference.
- Anonymous browsing remains useful.
- Account features enhance the platform rather than gate basic discovery.
