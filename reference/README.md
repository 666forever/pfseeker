# Reference material only

`assessed-site/` contains the files supplied for the earlier assessment of another website.

Use them to understand product concepts and known engineering problems. Do not import these files into the pfseeker production build.

Prohibited reuse includes:

- branding and logos
- page copy and content
- analytics IDs
- advertising IDs or scripts
- OAuth configuration
- API endpoints
- copied vendor architecture
- direct layout duplication

See `../docs/REFERENCE_ASSESSMENT.md` for the distilled findings.
